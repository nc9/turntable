## The classifier

`bun scripts/ci-classify.ts --base <sha> --head <sha> [--json]` maps the diff to the ci.yml jobs and prints the affected workspaces and, for each job, whether it would run and why.

- Workspaces come from the bun workspace graph (`packages/*/package.json`: dependencies, devDependencies, peerDependencies), with reverse dependents included.
- Global inputs run everything: `bun.lock`, the root `package.json`, `tsconfig.base.json`, `bunfig.toml`, formatter and editor config, the `Dockerfile` (toolchain pins), `.github/**` and `scripts/**`.
- A docs-only diff (`docs/**`, `*.md`, `*.mdx`) runs the docs job only, plus `check` for a generated page and `runner-image` for `docs/compatibility.mdx`.
- It fails open: an empty diff, a git error, a bad argument, an unknown top-level path or a file in an unknown package directory runs every job.

`scripts/ci-classify.test.ts` holds the table of example diffs (a ui-only change skips postgres and act-runner e2e; a db change runs postgres).

## Report-only rollout

The merge_group run prints the classification beside the full pipeline and changes no job. Compare it with real failures for a week: a job that failed on a stack the classifier would have skipped blocks the switch. The workflow step is staged in `.longshore/staged-workflows/ci-classify-report.yml` until the workflow owner applies it.
