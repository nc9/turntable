## Commands

| Command | Description |
| --- | --- |
| `turntable serve` | Start the server. |
| `turntable version` | Print the version. `--version` also works. |
| `turntable help` | Print usage. |

## `serve` flags

| Flag | Default | Description |
| --- | --- | --- |
| `--port` | `8080` | TCP port, 0 to 65535. |
| `--host` | `127.0.0.1` | Interface to bind. Defaults to `TURNTABLE_HOST` when set. |
| `--data-dir` | `./data` | Directory that holds `turntable.db`. |

## Environment variables

| Variable | Description |
| --- | --- |
| `TURNTABLE_HOST` | Default for `--host`. The container image sets it to `0.0.0.0`. |

## Endpoints

| Path | Description |
| --- | --- |
| `GET /healthz` | JSON `{ "ok": true, "version": "..." }`. |
| `GET /` | Placeholder page. The web UI is planned. |

Only `GET` and `HEAD` are accepted today. Responses carry a strict content security policy.

More settings arrive with each feature, and this page ships with them.
